# luvus-prompt-library

A luvus module: a sidebar dock for stored prompts kept as hierarchical
markdown files. Edit prompts inline (the luvus "Open files with" editor,
fallback `nvim`) or in an external editor (zed, VS Code), and right-click a
prompt to send it to any live pane in the active workspace.

Status: planning. See [PLAN.md](PLAN.md) — the approved plan is also filed as
the seed issue; work will be tracked from there.

## Install (once the module exists)

```sh
luvus module install <owner>/luvus-prompt-library
```
